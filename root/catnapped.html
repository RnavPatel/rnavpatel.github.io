Catnapped:
Return of the Order of the W.O.O.F

Premise

A stealth based platformer where players must help Agent Furball crawl, climb, and claw their way throughout the game to save Duchess Fluffy of Kittysburgh and take down the Order of the W.O.O.F.

Role & Scope

I was lead aritst on 2D environment art and prop design, and lead UI/UX designer for interface and instructional assets. I also assisted with character art for Agent Furball.

Tools

Unity 6
Adobe CC
Procreate

Narrative

Superspy Cats vs. Cyborg Dogs.

When world leaders’ cats vanish, Agent Furball must infiltrate the cyborg dogs' secret lair to rescue Duchess Fluffy and stop The Order of the W.O.O.F. before they replace all felines.

World Building

Setting the stage: the Secret Lair.

The 2D noir-style sewer lair of a cyborg dog society was brought to life through modular platformer units, and small easter eggs to emphasizing environmental storytelling.

UI Concept

Integrating the UI into the story.

The UI blends a spy-inspired aesthetic with accessibility, using redacted case file motifs for menus and type-stamp tutorials, and a distinct palette for legibility while immersing players in the game’s narrative.

Process

Refining the visual direction.

These iterations, guided by playtesting and developer feedback, refined the art and UI to enhance legibility and address key concerns.

UI and branding development for screens, and in-game assets.
Process for making a modular tile system to create platforms and walls for the sewer lair environment.
